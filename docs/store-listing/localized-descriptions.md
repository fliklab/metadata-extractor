# Localized Chrome Web Store descriptions

Use the matching language selector in the Chrome Web Store Developer Dashboard
before pasting each detailed description. Locale availability comes from the
corresponding `_locales` directory in the extension package.

## English (`en`)

Meta Checker is your metadata mate for GEO and SEO.

Compare metadata in the live DOM with the original HTML response to understand
what search engines, AI crawlers, and users may encounter. Meta Checker clearly
marks values that stayed the same, were added at runtime, changed after loading,
or disappeared from the final DOM.

Inspect essential tags, Open Graph data, canonical and language signals, robots
directives, HTTP response details, and JSON-LD summaries in one focused popup.
Choose the sections and fields that matter to your workflow and view complete
source tags when you need deeper technical context.

Meta Checker provides technical metadata inspection. It does not predict or
guarantee search rankings or visibility in AI-generated answers.

## 日本語 (`ja`)

Meta Checker は GEO と SEO のためのメタデータパートナーです。

現在の DOM と最初の HTML レスポンスのメタデータを比較し、検索エンジン、
AI クローラー、ユーザーが確認する可能性のある情報の差を把握できます。
変わらない値、実行時に追加された値、読み込み後に変更された値、最終 DOM
から削除された値を明確に区別します。

基本メタタグ、Open Graph、canonical、言語シグナル、robots ディレクティブ、
HTTP レスポンス、JSON-LD の概要を一つのポップアップで確認できます。必要な
セクションと項目を選び、詳しい技術情報が必要な場合は元のタグ全体を表示できます。

Meta Checker は技術的なメタデータ確認ツールです。検索順位や AI 回答での
表示を予測または保証するものではありません。

## Español (`es`)

Meta Checker es tu aliado de metadatos para GEO y SEO.

Compara los metadatos del DOM actual con la respuesta HTML original para entender
qué pueden encontrar los motores de búsqueda, los rastreadores de IA y los usuarios.
Meta Checker distingue claramente los valores que no cambiaron, los añadidos durante
la ejecución, los modificados después de cargar la página y los eliminados del DOM final.

Revisa etiquetas esenciales, Open Graph, señales canonical y de idioma, directivas
robots, detalles de la respuesta HTTP y resúmenes JSON-LD en una sola ventana. Elige
las secciones y los campos relevantes y consulta la etiqueta original completa cuando
necesites más contexto técnico.

Meta Checker ofrece una inspección técnica de metadatos. No predice ni garantiza
posiciones en buscadores ni visibilidad en respuestas generadas por IA.

## Português do Brasil (`pt_BR`)

Meta Checker é seu parceiro de metadados para GEO e SEO.

Compare os metadados do DOM atual com a resposta HTML original para entender o que
mecanismos de busca, rastreadores de IA e usuários podem encontrar. O Meta Checker
distingue valores que permaneceram iguais, foram adicionados durante a execução,
alterados após o carregamento ou removidos do DOM final.

Confira tags essenciais, Open Graph, sinais de canonical e idioma, diretivas robots,
detalhes da resposta HTTP e resumos JSON-LD em uma única janela. Escolha as seções e
os campos importantes para o seu fluxo e veja a tag original completa quando precisar
de mais contexto técnico.

O Meta Checker oferece inspeção técnica de metadados. Ele não prevê nem garante
posições em mecanismos de busca ou visibilidade em respostas geradas por IA.
